## Survey App

This project contains a simple Flask application that allows creating surveys, sending links to respondents and visualising responses as a small force-directed graph. It is only a demo and stores everything in memory.

### Running

Install requirements (Flask) and run the app:

```bash
pip install Flask
python survey_app/app.py
```

Open `http://localhost:5000/create` to create a new survey.
