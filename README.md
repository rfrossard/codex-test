# codex-test

Este repositório contém uma demonstração simples de uma página com estilo inspirado no site do Itaú. A página inclui um exemplo de gráfico gerado com D3.js.

## Executando

1. Clone o repositório e abra `index.html` em um navegador moderno.
2. O gráfico é gerado com D3 carregado via CDN, portanto não é necessária configuração adicional.

## Estrutura

- `index.html` – página principal.
- `style.css` – estilos com cores e animações simples.
- `graph.js` – script que gera um gráfico de barras com D3.
